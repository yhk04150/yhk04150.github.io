SwinProbeFormer

Enhancing Wafer Probing With SwinProbeFormer: Self-Supervised Anomaly Detection via Window-Based Swin Transformer

Original paper / DOI ↗Industry project →

Abstract

Research summary

Wafer probing motion faults can jeopardize probing reliability, while conventional attention is expensive for long sensor sequences. SwinProbeFormer is designed for self-supervised overgain detection.

Proposed method

Uses local window attention and cyclic shifts, with domain-informed synthetic anomaly injection to train on normal sensor data.

Experimental results

0.9493F1 on the reported wafer-probing benchmark
34.8%Relative F1 improvement vs. AnomalyBERT (CV)
9,796 → 5,824 MBGPU memory in the project comparison

GPU memory values are from the project evaluation.

Research impact

High detection performance with reduced memory supports equipment-side monitoring and early fault identification.
