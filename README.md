## Deploy on GitHub Pages

1. Create a public repository named `yhk04150.github.io` (or use the existing user-site repository after backing it up).
2. Upload the contents of this folder to the root, including `projects/` and `.nojekyll`.
3. In Settings → Pages, choose Deploy from a branch → main → /(root), then Save.
4. Open the URL shown in Pages once deployment succeeds.

For a project repository instead, use the URL displayed in Pages and update the README link.

## Local preview

Open `index.html` or run `python -m http.server 8000` from this folder. No build or third-party dependencies required.
