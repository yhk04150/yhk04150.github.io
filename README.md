# Hyekyung Yoon — Research & Engineering Portfolio

A static GitHub Pages website. Upload the contents of this folder to the repository root and enable Pages from the main branch.

- `index.html`: research areas, projects, publications, education and credentials.
- `projects/`: industry project pages and semiconductor overview.
- `publications/`: nine research detail pages.
- `assets/`: profile, project and publication visuals.
- `style.css`, `script.js`: responsive styling and project filtering.
